WHAT CHANGES
- My owner workspace is always available via the authenticated self context, even
  when a cached/partial initial roster omitted it. No extra reseller login/tenant.
- Shared owner selection and a direct Use my owner workspace action in branding,
  trials, Library layouts/settings/device profiles and new-device defaults.
- Workspace search is server-paginated, not silently limited to the first page.
- Dashboard/customers/devices/activity log have explicit own-workspace filters;
  All workspaces preserves the owner's aggregate administration view.
- Workspaces & panel links includes the owner row and owner shortcuts/allocation.
  An owner cannot suspend its own workspace through the reseller suspension action.
- The header names the actual scope. Owner-held devices are not labelled as needing
  removal from a reseller merely because their detached flag is false.
- Owner APIs resolve missing tenant_id to the existing owner workspace for supported
  resource creation/read operations. Cross-tenant reseller requests still fail.
- The existing single-account pilot is displayed accurately and remains hard bounded.

WHAT DOES NOT CHANGE
MarcPanel's permanent link, brand/package/artwork, centrally signed APKs/updater,
current approved plan/default/offer/counter, contact retention, saved native data,
viewing rights, payment/activation/auth services and production release policy.
This does not create a trial, move customers/devices or enable new default actions.
